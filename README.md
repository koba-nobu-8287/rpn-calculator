# rpn-calc

HP-16Cを参考にした、端末で使えるプログラマ向けRPN電卓です。1～64ビットの整数で進数変換やビット演算ができ、小数を扱うときは `f64` に切り替えられます。対話モードでスタックを見ながら計算することも、スクリプトから式を1つ渡して結果を受け取ることもできます。

## ビルドして最初の式を実行する

GitとRust（Cargoを含む）が必要です。Windowsでの動作確認環境はRust 1.94.1です。以下はPowerShellでの例です。

```powershell
git clone --branch develop https://github.com/koba-nobu-8287/rpn-calculator.git
cd rpn-calculator
cargo build --release --bin rpn-calc
.\target\release\rpn-calc.exe --base dec "5 3 + 2 *"
```

出力は `16` です。RPN（逆ポーランド記法）では数値を先に、演算子を後に入力します。`5 3 +` でスタックの先頭（X）が8になり、続く `2 *` で16になります。**起動時の既定は16進数**なので、10進数で計算したいときは `--base dec` を指定します。

## 対話モード

式を省いて起動すると、行をまたいでスタックとレジスタを使えます。

```powershell
.\target\release\rpn-calc.exe --base dec
```

次の各行を順に入力します。

| 入力 | 結果 |
|---|---|
| `5 3 +` | `8` |
| `2 *` | 直前の8を使って `16` |
| `sto 0` | レジスタ0に16を保存 |
| `clx` | Xが `0` になる |
| `rcl 0` | 保存した `16` をXに呼び出す |
| `stack` | 4段を上からT、Z、Y、Xの順に表示 |
| `exit` | 対話を終了 |

`status` で現在の基数・ワード長・フラグなどを確認できます。対話中の `help` は操作の案内、起動時の `--help` は引数の案内です。

## 整数の基数・幅・符号を選ぶ

| 起動オプション | 指定値 | 既定 |
|---|---|---|
| `--base` | `bin`、`oct`、`dec`、`hex` | `hex` |
| `--word-size` | 1～64ビット | 16 |
| `--signed` | `unsigned`、`ones`（1の補数）、`twos`（2の補数） | `twos` |
| `--register-count` | 1～1024個。レジスタ番号は0から | 16個 |
| `--float` | 浮動小数点モード。基数は10進 | 省略時は整数 |

式の途中でも設定を変更できます。たとえば `hex FF dec 10 +` は、16進のFF（255）と10進の10を足し、10進で `265` を返します。整数の2・8・16進表示はビット列を、10進表示は選択した符号形式で解釈した値を示します。

| 式 | 結果 | 用途 |
|---|---|---|
| `hex wsize 8 signed twos FF dec` | `-1` | 8ビットのFFを2の補数として読む |
| `hex wsize 8 signed unsigned FF dec` | `255` | 同じビット列を符号なしで読む |
| `hex wsize 8 A5 0F and` | `5` | 下位4ビットを取り出す |
| `float 7 2 /` | `3.5` | 小数を含む商を求める |

1の補数では、既定の `oneszero canonical` が算術結果の負のゼロを正のゼロに揃えます。`oneszero raw` に切り替えると、演算で生じたゼロの符号を保持します。

## 数値の一括入力とキー入力

通常の式では、空白で区切った数値を1個ずつスタックに積みます。`keys "..."` を使うと、電卓のキーを順番に押す操作になり、数字は編集中の値に追記されます。次は10進の対話モードに入力する例です。

| 入力 | 結果 |
|---|---|
| `7 2 sub` | 完成した2つの数値で 7 − 2 を計算し、Xが5になる |
| `keys "7 enter 2 -"` | キー操作で同じ減算を行い、Xが5になる |
| `keys "1 2 enter"` | 数字をつないで12を入力し、ENTERで複製する。XとYがともに12になる |

通常の式の減算は `sub` です。単独の `-` は数値の正のゼロとして扱います。整数の一括入力では指定幅の下位ビットを採用するため、たとえば `hex wsize 8 0x123` は `23` になります。キー入力では、指定幅の範囲を超える桁を入力した時点でエラーになります。

## スクリプトから呼び出す

ワンショットでは、式全体を1つの引数として渡します。成功時の標準出力は最終Xと改行だけです。失敗時は診断を標準エラーに出力します。起動ごとに新しいスタックとレジスタで始まります。

```powershell
$result = .\target\release\rpn-calc.exe --base dec "7 2 sub"
if ($LASTEXITCODE -eq 0) { $result }  # 5
```

| 終了コード | 意味 |
|---|---|
| 0 | 正常終了 |
| 1 | キー入力・計算エラー（ゼロ除算など） |
| 2 | 起動引数・行の構文・数値リテラルのエラー |
| 3 | 入出力エラー |

対話モードでは通常のエラーを表示した後も次の行を入力できます。行の構文エラーではその行全体が未実行になります。実行中の計算エラーでは、それまでに成功した操作が残ります。

## HP-16Cとの対応範囲

4段スタック、LAST X、直接指定のSTO/RCL、整数の論理演算・シフト・回転を利用できます。浮動小数点にはRustの `f64` の精度と範囲を採用しています。HP-16Cのプログラム記録・分岐・サブルーチンは対象外です。繰り返しや条件分岐には外部スクリプトを使います。
